# 🔥 Smart Fire Emergency Alert System

A Python Flask based Smart Fire Emergency Alert System.

## Features

- Admin Login
- Fire Emergency Reporting
- Admin Contact
- Call Admin
- Fire Location
- Google Maps Link
- Emergency Description
- Active Alerts
- Resolved Alerts
- Alert History
- Emergency Contacts
- SQLite Database
- Dashboard

## Technologies

- Python
- Flask
- SQLite
- HTML
- CSS
